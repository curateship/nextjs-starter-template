# Common Mistakes

- Local dev uses a local Postgres database. Production runs on a Hetzner VPS managed by Coolify. Use the Coolify MCP for server/database operations when needed.
- Always use shadcn/ui components for UI. Don't build custom components when a shadcn equivalent exists.
- Always add comments to your code. Every function, block of logic, and non-obvious line should have a comment.
