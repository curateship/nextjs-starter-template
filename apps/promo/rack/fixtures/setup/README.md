# Setup check screens

What the setup check reads off a phone: the Play Store's auto-update box,
the phone's browser showing ipinfo.io's answer, and `dumpsys package` for an
app's location permission.

They were written from the screens' known layout, not dumped from a real
phone: no phone was on the rack when the setup check was written (14 Oct
2026). Save the real ones in their place once a phone has run the check.
