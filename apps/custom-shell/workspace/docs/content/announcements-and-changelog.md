# Announcements and changelog

The two publishing tools have different jobs:

- Announcements are short messages for a chosen audience. An admin can write,
  schedule, publish, unpublish, and delete them. A dismissal belongs to one
  person and does not hide the announcement for everyone else.
- The changelog is the longer record of product updates. Admins manage entries
  in the Changelog dashboard. Signed-in people read published entries on
  What's new, and a new entry can create notifications.

Both systems belong to the active workspace. Audience, publication state, and
time decide whether a record appears. Preview and admin lists may show records
that public or member views must hide.

- Use an announcement for a message that should appear now and may be dismissed.
- Use a changelog entry for an update people should find later.
