# Account security

The Security tab waits to load until somebody opens it. Switching to another
account tab unmounts Security, but the account window keeps the three password
fields in memory until the person comes back.

The account window treats any text in those fields as unsaved work. Escape, the
close button, the backdrop, and Done ask before discarding it. A confirmed close
clears every password field. A successful password change clears them too.

"Sign out all other devices" asks for confirmation before it ends any sessions.
The question names the number of other devices, explains that the current device
stays signed in, and cannot close while the request runs.
