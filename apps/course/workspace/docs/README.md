# This app's docs

What is true of this app and no other. The app was called systemeverything,
in `apps/systemeverything`, until 17 Oct 2026, so older commits and notes use
that name. Its local database is still named `systemeverything`. Everything
true of every app built on Custom Shell lives in the repo's `docs/`, and
`docs/README.md` indexes it.

- `sites.md` — the many websites one deployment serves: what decides it,
  what `/` is, what belongs to one site and what every site shares, the
  Courses front page row, copying a site, and what going live needs.
- `courses.md` — written guides at `/courses`: the chapter editor, who can
  read what, free previews, held-back and dated chapters, what members can do
  in a chapter, Read aloud, and the Questions and Stats tabs.
- `pomoder-email-sequence.md` — the seven-email Pomoder flow in Automations:
  what it sends on which day, how long a list takes, and what to check before
  switching it on.
- `importing-the-old-contact-list.md` — the one-off script that brings
  systemeverything.com's 25,100 contacts across, what it carries, what it leaves
  behind, and the broken tags it repairs on the way in.
- `shell-integration.md` — what this app takes from Custom Shell, what it
  keeps of its own, and what each shell merge carried across.
